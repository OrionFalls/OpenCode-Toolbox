# Changelog

## 0.2.37

- Toolbox UI: полностью удалён общий блок Modules; оставлен отдельный переключатель True Model Disabler. Provider Disabler, Bulk Model Toggle, MCP-GUI и Custom Providers всегда активны.
- MCP-GUI: исправлено чтение настроек через ToolboxIpc (ранее вызывался отсутствующий getSettings на McpIpc); страница регистрируется по тому же шаблону, что Custom Providers.
- Provider Disabler и Bulk Model Toggle: серверные transforms больше не зависят от флагов модулей, которые в пользовательском интерфейсе больше не существуют.
- Добавлен watcher общего файла настроек: после изменения provider/model overrides сервер автоматически вызывает provider.reload() и model.reload(), без ручного перезапуска Desktop.
- Bulk Model Toggle упрощён до выбора провайдера и двух кнопок Enable all / Disable all; удалены счётчики и Reset overrides.
- Установщик включает новый settings-watcher; синхронизированы версия, README и CHANGELOG.

## 0.2.36

- Исправлена некорректная запись переноса строки в регрессионном тесте кнопки Reload; добавлена корректная проверка вызова `webContents.reload()` и отсутствия `app.relaunch()` / `app.exit()`.
- Синхронизированы package metadata, GUI, серверный лог, README и CHANGELOG.

## 0.2.35

- Кнопка Restart OpenCode теперь выполняет ту же операцию, что и меню Desktop «Вид → Перезагрузить»: вызывает `webContents.reload()` для текущего активного окна. Приложение не закрывается и не запускается заново.
- Удалены `app.relaunch()` / `app.exit(0)` и лишнее подтверждение перезапуска.
- Обновлены package metadata, GUI, серверный лог, README и CHANGELOG.

## 0.2.34

- Кнопка Restart OpenCode теперь запрашивает подтверждение и предупреждает о возможной потере несохранённого ввода перед закрытием окон и перезапуском Desktop.
- Синхронизированы package metadata, GUI, серверный лог, README и CHANGELOG.

## 0.2.33

- Исправлено устаревшее тестовое ожидание IPC после переноса регистрации Custom Providers за проверку флага модуля; теперь тест проверяет актуальный асинхронный путь чтения настроек.
- Синхронизированы package metadata, GUI, серверный лог, README и CHANGELOG.

## 0.2.32

- Toolbox: нижние панели Provider Disabler и Bulk Model Toggle отображаются только при включённых соответствующих модулях.
- MCP-GUI: исправлена причина отсутствия страницы — функция регистрации существовала, но не вызывалась из GUI setup. Страница и команда теперь появляются только при включённом модуле.
- Custom Providers: страница и команда больше не регистрируются, когда модуль выключен.
- Добавлена кнопка Restart OpenCode рядом с Refresh. Она вызывает штатный Electron app.relaunch() и app.exit(0), чтобы применить серверные provider/model transforms после изменения настроек.
- Обновлены версия серверного лога, package metadata, GUI, README и CHANGELOG.

## 0.2.31

- Исправлен IPC-контракт GUI: страницы Custom Providers и MCP-GUI обращались к несуществующему `getModuleSettings`, тогда как main process предоставлял `getSettings` с JSON-строкой.
- Обе страницы теперь вызывают объявленный IPC-метод и безопасно разбирают настройки до чтения флагов модулей.
- Добавлен регрессионный тест, проверяющий согласованность GUI IPC-вызовов с контрактом ToolboxIpc.
- Синхронизированы версия, README и CHANGELOG.

## 0.2.30

- Исправлена критическая ошибка Windows-установщика: ранее он не загружал каталог `modules/`, хотя серверная точка входа импортирует из него четыре обязательных файла. Из-за отсутствующих модулей серверная часть не запускалась, поэтому Desktop не мог загрузить GUI Toolbox.
- Установщик теперь создаёт вложенные каталоги, загружает все runtime-модули и материалы лицензии Custom Providers, затем проверяет наличие обязательных файлов до замены установленной версии.
- Добавлен регрессионный тест, сверяющий локальный install manifest с импортами серверной точки входа и GUI/package exports.
- Синхронизированы package metadata, GUI, серверный лог, README и CHANGELOG.

## 0.2.29

- Windows installer: удалён случайно продублированный фрагмент `Download-ToolboxFile`, который оказался после основного сценария установки и делал `install.ps1` синтаксически некорректным.
- Проверена целостность структуры установщика; исправление TLS-загрузки версии 0.2.28 сохранено.
- Синхронизированы package metadata, GUI, серверный лог, README и CHANGELOG.

## 0.2.28

- Windows installer: добавлен fallback скачивания через GitHub Contents API, если raw.githubusercontent.com недоступен или curl.exe/Schannel завершает TLS-передачу ошибкой.
- Для основного raw-запроса принудительно используется HTTP/1.1 как обход несовместимости отдельных Schannel/proxy-конфигураций с HTTP/2.
- Ошибки обоих каналов загрузки теперь объединяются в диагностическое сообщение; проверка пустого файла сохранена.
- Синхронизированы package metadata, GUI, серверный лог, README и CHANGELOG.


## 0.2.27

- Bulk Model Toggle: добавлена команда Reset overrides для выбранного провайдера — удаляет только его сохранённые enabled overrides и возвращает управление штатным значениям каталога.
- В GUI отображается количество сохранённых overrides; кнопки массового включения/отключения недоступны, если у выбранного провайдера нет моделей.
- Добавлен серверный helper для сброса overrides и unit-тесты на выборочный сброс без затрагивания других провайдеров.
- Синхронизированы package metadata, GUI, серверный лог, README и CHANGELOG.

## 0.2.26

- True Model Disabler: добавлен короткий кеш Desktop visibility policy (1,5 секунды по умолчанию) и объединение одновременных запросов чтения; не открывает SQLite для каждого model call.
- Добавлены unit-тесты фактического SDK hook: скрытая модель отклоняется, конкурентные вызовы используют один policy read (исправлен импорт registerTrueModelDisabler в test suite).
- Bulk Model Toggle безопасно игнорирует некорректные контейнеры overrides; добавлены проверки отключённого модуля и некорректных записей.
- Добавлены регрессионные проверки Provider Disabler: обновляется только явно отключаемый провайдер; остальные записи и native disabled state остаются нетронутыми.
- Синхронизированы package metadata, серверный лог, GUI, README и CHANGELOG.
