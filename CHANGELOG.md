# Changelog

## 0.2.43

- True Model Disabler: вместо кешируемого события `aisdk.hook(\"sdk\")` используется защитная обёртка `LanguageModelV3.doGenerate` / `doStream`. Политика проверяется непосредственно перед каждым запросом, в том числе при повторном использовании адаптера в старых диалогах и субагентах.
- True Model Disabler остаётся обёрнутым даже при выключенном переключателе модуля: повторное включение начинает защищать уже созданные адаптеры без обхода через кеш SDK.
- Убран кеш готовой visibility policy по умолчанию (1,5 секунды); свежая SQLite-политика читается для каждой генерации, одновременные чтения объединяются. Поведение fail-open при недоступности Desktop DB сохранено.
- Сохранён Bulk Model Toggle из 0.2.42: он изменяет только нативные `user[].visibility` (`show` / `hide`), а не `Model.Info.enabled` и не provider catalog. Регрессионные проверки охватывают прежние сессии, потоковую генерацию и субагентов.
- Синхронизированы README, GUI version, серверный лог и package metadata.


## 0.2.42

- Bulk Model Toggle полностью переведён на нативную модель видимости OpenCode Desktop: сохраняет `user[].visibility = show/hide` в `drafts.sqlite` (`opencode.global.dat:model`).
- Удалён provider transform, изменявший `Model.Info.enabled` и приводивший к исчезновению раздела провайдера. Массовое переключение больше не меняет каталог моделей.
- После обновления видимости окна Desktop автоматически перезагружаются, чтобы обновить in-memory storage.
- Удалены устаревшие `providerEnabledOverrides` и `modelEnabledOverrides` из настроек Toolbox; сохранена независимость Provider Disabler.
- Добавлены тесты для сохранения, повторного включения и защиты настроек других провайдеров.


## 0.2.41

- Bulk Model Toggle: массовое изменение `enabled` больше не вызывает принудительный reload каталога провайдера, который приводил к исчезновению строк Models. Сохранение выполняется через общий файл настроек; watcher повторно применяет provider transform.
- Добавлена регрессионная проверка отсутствия provider reload при Disable all / Enable all.
- Синхронизированы версия и документация.


## 0.2.40

- Provider Disabler: отключённые провайдеры, отсутствующие в активном каталоге OpenCode, теперь остаются в интерфейсе Toolbox по сохранённому ID и могут быть включены повторно.
- Bulk Model Toggle: массовое включение/отключение перенесено с runtime model transform на исходные определения моделей через provider transform; модели не удаляются из списка Models и сохраняют штатные переключатели.
- Добавлен provider-level `providerEnabledOverrides`; сохранена обратная совместимость с ранее записанными per-model `modelEnabledOverrides`.
- Обновлены регрессионные тесты, README, версия GUI и серверный лог.

- Синхронизированы package metadata, GUI, серверный лог, README и CHANGELOG.

## 0.2.37

- Bulk Model Toggle упрощён до выбора провайдера и двух кнопок Enable all / Disable all; удалены счётчики и Reset overrides.
- Установщик включает новый settings-watcher; синхронизированы версия, README и CHANGELOG.
