# OpenCode Toolbox

**Модульный набор расширений для OpenCode Desktop.**

Версия: **0.2.25**.

Toolbox поставляется как единый плагин: серверная часть и GUI Desktop используют общую идентичность плагина. В GUI доступны отдельные страницы Toolbox, MCP-GUI и Custom Providers.

## Модули

| Модуль | Назначение | Состояние |
| --- | --- | --- |
| True Model Disabler | Блокирует вызовы моделей, скрытых штатными настройками OpenCode, включая вызовы субагентов. | Проверяет show/hide policy при вызове, включая субагентов. При недоступности внутреннего Desktop-хранилища временно отключается с предупреждением (fail-open); требуется runtime-проверка в Desktop |
| Provider Disabler | Временно отключает провайдеры без удаления ключей и моделей. | UI-переключатели реализованы; состояние хранится в opencode-toolbox.json, применение после перезапуска OpenCode Desktop |
| Bulk Model Toggle | Массово включает/отключает модели провайдера с сохранением overrides. | UI-кнопки Enable all / Disable all реализованы; overrides хранятся по provider/model ID и применяются после перезапуска OpenCode Desktop |
| MCP-GUI | Создание, редактирование, отключение и удаление MCP-серверов. | GUI интегрирован: local/remote, mcp.servers, disabled и удаление. MCP-GUI является единственным источником состояния disabled, чтобы серверная политика не перезаписывала выбор пользователя. |
| Custom Providers | Управление кастомными API-провайдерами и моделями. | **GUI интегрирован** как страница OpenCode Toolbox |

## Установка и обновление на Windows

```powershell
irm https://raw.githubusercontent.com/OrionFalls/OpenCode-Toolbox/main/install.ps1 | iex
```

Повторный запуск проверяет наличие обновления и устанавливает актуальную опубликованную версию. После обновления полностью перезапустите OpenCode Desktop.

## Проверка

Файл общих настроек нормализует значения модулей, отключённых провайдеров, MCP-серверов и overrides моделей. Запись настроек выполняется через временный файл с атомарным переименованием, чтобы частичное сохранение не повредило состояние.

```bash
npm run check
npm test
```

Проверка синтаксиса не заменяет тестирование внутри OpenCode Desktop.

## Архитектурные ограничения

Публичный OpenCode GUI SDK позволяет добавлять собственные SettingsPage, Commands, Panels и IPC между GUI-окнами и Electron main process. Он не документирует точки расширения для встраивания контролов внутрь нативных вкладок Providers и Models. Поэтому соответствующие функции не маскируются под встроенные элементы: до появления поддерживаемого API они будут размещаться на собственных страницах Toolbox.

## Настройки модулей

MCP-GUI и Custom Providers выключены по умолчанию, пока пользователь явно не включит их. Их GUI-страницы и команды регистрируются только при включённом соответствующем модуле. Список `disabledMcpServers` является частью общего файла настроек и сохраняет независимое состояние каждого MCP-сервера.

GUI и серверная часть используют общий файл `opencode-toolbox.json` в каталоге конфигурации OpenCode (рядом с `opencode.jsonc`). Переключатели модулей, отключённые провайдеры и массовые overrides моделей сохраняются в этом файле. Для применения изменений серверных трансформаций требуется перезапустить OpenCode Desktop.

Модули MCP-GUI и Custom Providers также учитывают свои флаги включения при регистрации GUI-страниц; после изменения флага требуется перезапуск Desktop.
