# OpenCode Toolbox

**Модульный набор расширений для OpenCode Desktop.**

Версия: **0.2.1**.

Toolbox развивается как единый плагин. Серверная часть использует официальный OpenCode Plugin API, а интерфейс — Desktop GUI API. Модули проектируются независимо, чтобы их можно было включать и отключать без удаления конфигурации.

## Модули

| Модуль | Назначение | Состояние этой версии |
| --- | --- | --- |
| True Model Disabler | Проверяет штатные настройки видимости моделей перед вызовом модели. Не изменяет каталог и не трогает `enabled`; блокировка применяется также к субагентам. | Серверная защита перенесена |
| Provider Disabler | Временно отключает провайдеры без удаления ключей и моделей. | Серверная трансформация и сохранение состояния подготовлены; UI-переключатели в работе |
| Bulk Model Toggle | Включает/отключает модели выбранного провайдера массово. | Постоянная трансформация и запись массовых overrides подготовлены; UI-кнопки в работе |
| MCP-GUI | Создание, редактирование, отключение и удаление MCP-серверов. | API-слой подготовлен; UI в работе |
| Custom Providers | Управление кастомными провайдерами и моделями. | Перенос исходного интерфейса и интеграция в работе |

## Совместимость

- OpenCode Desktop с поддержкой GUI-плагинов.
- OpenCode Plugin API V2.
- Node.js 20+ для проверок пакета; серверная среда OpenCode предоставляет Bun.
- Windows PowerShell 5.1+ для установщика.

## Установка и обновление на Windows

В PowerShell:

```powershell
irm https://raw.githubusercontent.com/OrionFalls/OpenCode-Toolbox/main/install.ps1 | iex
```

Повторный запуск той же команды проверяет обновления и устанавливает последнюю версию. После обновления полностью перезапустите OpenCode Desktop.

## Разработка

```bash
git clone https://github.com/OrionFalls/OpenCode-Toolbox.git
cd OpenCode-Toolbox
npm run check
```

## Архитектурные правила

- Настройки модулей хранятся в plugin-scoped storage OpenCode.
- Модели не удаляются из каталога ради имитации запрета.
- Отключение провайдера не удаляет его настройки, API-ключи и модели.
- MCP-серверы отключаются через `disabled`, а не удаляются; удаление — отдельное явное действие в UI.
- Bulk Model Toggle получает актуальный список моделей непосредственно из OpenCode.
- Любое изменение версии сопровождается обновлением README и CHANGELOG.

## Заимствованный код и авторство

Оригинальный GUI-модуль сохранён без переименования API и с оригинальным уведомлением в `vendor/custom-provider/gui-experimental.cjs`. Он пока не загружается как отдельный плагин: сначала выполняется интеграция его IPC и страницы в Toolbox, чтобы не создавать конфликтующие установки.

Модуль **Custom Providers** основан на проекте [MoGLCL/opencode-custom-provider](https://github.com/MoGLCL/opencode-custom-provider), автор MoGlitch. Проект распространяется по лицензии MIT. При переносе исходных файлов сохраняются оригинальные уведомления об авторских правах и текст лицензии. В интерфейсе Toolbox также указывается авторство исходного проекта.
