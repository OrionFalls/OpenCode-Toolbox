# OpenCode Toolbox

**Модульный набор расширений для OpenCode Desktop.**

Версия: **0.2.43**.

Toolbox поставляется как единый плагин: серверная часть и GUI Desktop используют общую идентичность плагина. В GUI доступны отдельные страницы Toolbox, MCP-GUI и Custom Providers.

## Модули

| Модуль | Назначение | Состояние |
| --- | --- | --- |
| True Model Disabler | Блокирует вызовы моделей, скрытых штатными настройками OpenCode, включая вызовы субагентов. | Проверяет show/hide policy непосредственно перед каждым `doGenerate` и `doStream`, включая старые сессии и субагентов. Оборачивает кешируемый OpenCode language adapter, поэтому повторное использование SDK не обходит проверку. Чтение SQLite выполняется перед каждым запросом; одновременные чтения объединяются. При недоступности Desktop-хранилища временно работает в fail-open с предупреждением. |
| Provider Disabler | Временно отключает провайдеры без удаления ключей и моделей. | Переключатели сохраняют ID отключённых провайдеров; неактивные провайдеры остаются в списке Toolbox как строки восстановления и могут быть включены повторно. |
| Bulk Model Toggle | Массово меняет штатную видимость моделей OpenCode (`show` / `hide`) в Desktop-хранилище. Не меняет `enabled` и не удаляет модели или провайдеры из каталога. | Компактный интерфейс: выпадающий список провайдера и две кнопки Enable all / Disable all; изменения применяются автоматически. |
| MCP-GUI | Создание, редактирование, отключение и удаление MCP-серверов. | Отдельная SettingsPage и команда навигации; local/remote, mcp.servers, disabled и удаление.
| Custom Providers | Управление кастомными API-провайдерами и моделями. | **GUI интегрирован** как страница OpenCode Toolbox |

## Установка и обновление на Windows

```powershell
irm https://raw.githubusercontent.com/OrionFalls/OpenCode-Toolbox/main/install.ps1 | iex
```

Установщик загружает не только точки входа, но и все обязательные файлы `modules/`, а также лицензионные материалы Custom Providers. Перед заменой проверяет комплектность пакета. Повторный запуск проверяет наличие обновления и устанавливает актуальную опубликованную версию. Если raw.githubusercontent.com недоступен или Schannel завершает TLS-соединение с ошибкой, установщик автоматически переключается на GitHub Contents API. После обновления полностью перезапустите OpenCode Desktop.

## Проверка

Файл общих настроек нормализует значения модулей, отключённых провайдеров, MCP-серверов и overrides моделей. Запись настроек выполняется через временный файл с атомарным переименованием, чтобы частичное сохранение не повредило состояние.

```bash
npm run check
npm test
```

Проверка синтаксиса не заменяет тестирование внутри OpenCode Desktop. После обновления перезапустите OpenCode Desktop, чтобы серверный плагин зарегистрировал защитную обёртку языковых моделей.

## Архитектурные ограничения

Публичный OpenCode GUI SDK позволяет добавлять собственные SettingsPage, Commands, Panels и IPC между GUI-окнами и Electron main process. Он не документирует точки расширения для встраивания контролов внутрь нативных вкладок Providers и Models. Поэтому соответствующие функции не маскируются под встроенные элементы: до появления поддерживаемого API они будут размещаться на собственных страницах Toolbox.

## Настройки модулей

True Model Disabler — единственный модуль с пользовательским переключателем. Provider Disabler, Bulk Model Toggle, MCP-GUI и Custom Providers включены постоянно и не управляются отдельными флагами. MCP-GUI и Custom Providers регистрируют собственные страницы настроек в левом меню. Список `disabledMcpServers` является частью общего файла настроек и сохраняет независимое состояние каждого MCP-сервера.

GUI и серверная часть используют общий файл `opencode-toolbox.json` в каталоге конфигурации OpenCode (рядом с `opencode.jsonc`). Переключатель True Model Disabler, отключённые провайдеры и флаги массового включения моделей по провайдерам сохраняются в этом файле. Серверный плагин следит за изменениями файла и автоматически повторно применяет Provider Disabler. Bulk Model Toggle обновляет нативные настройки видимости `show` / `hide` в `drafts.sqlite` (state `opencode.global.dat:model`) и перезагружает окна Desktop для обновления хранилища.

GUI main process атомарно записывает настройки; серверный watcher отслеживает замену файла и вызывает `ctx.provider.reload()` и `ctx.model.reload()`. Provider Disabler сохраняет неактивные ID для восстановления; Bulk Model Toggle работает с тем же `user[].visibility`, что и штатные переключатели Settings → Models. Выключенные модели остаются в каталоге и отображаются с выключенными переключателями.
